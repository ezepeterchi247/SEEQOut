# SEEQOut Coding Standards

## Our Principles

1. Write clean code.
2. Write code that is easy to understand.
3. Never rush important features.
4. Every feature must solve a real problem.
5. Simplicity before complexity.
6. Security is never optional.
7. Performance matters.
8. Every screen should reduce stress and increase confidence.

## Folder Naming

Use lowercase letters.

Example:

backend

buyer_app

seller_portal

admin_dashboard

docs

## Comments

Only write comments when they help explain why something exists.

## Git Rule

Commit only when a feature is complete and working.
